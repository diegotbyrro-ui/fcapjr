# FCAP JR. — Site institucional

Site completo aprovado, preparado para iniciar o desenvolvimento do CRM.

## Estrutura
- `dist/`: 25 páginas HTML, estilos, JavaScript e todos os recursos visuais.
- `dist/assets/`: imagens, logos, fontes e metodologia.
- `dist/app.js`: menus, animações, soluções e metodologia.
- `dist/booking.js`: seleção de data e horário para solicitação de reunião.

## Executar localmente
Na pasta do projeto, execute `python -m http.server 8080 --directory dist` e abra http://localhost:8080.
Para hospedagem estática, publique o conteúdo de `dist/`.

## Continuidade
Leia `CRM_CONTEXTO.md`. O site não contém backend de CRM implementado.
A configuração `.openai/hosting.json` registra a publicação original em Sites; não é credencial.
